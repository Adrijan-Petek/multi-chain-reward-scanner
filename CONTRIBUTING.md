# Contributing

Thanks for helping improve Multi-Chain Reward Scanner.

## Setup

- Node.js 24+
- npm

```bash
npm install
```

## Local runs

- Live scan:
  ```bash
  npm run scan:once
  ```
- Offline dry scan:
  ```bash
  npm run scan:dry
  ```

## Guidelines

- Keep changes focused and well-scoped.
- Update `sample_reports/report-sample.json` if you change report structure.
